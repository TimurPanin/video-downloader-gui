# Использование Video Downloader GUI

## Быстрый старт

Установите зависимости и запустите приложение:

```bash
python -m pip install -r requirements.txt
python run.py
```

Основной модуль также можно запустить напрямую:

```bash
python app.py
```

Для MP3-извлечения FFmpeg должен быть доступен в `PATH`.

## Главное меню

В приложении доступны два основных режима:

- **YouTube** - загрузка отдельных видео и плейлистов
- **TikTok** - загрузка отдельных видео

Также доступны настройки папки загрузки, языка интерфейса и cookies.

## YouTube

### Отдельное видео

1. Откройте страницу YouTube.
2. Скопируйте ссылку на видео.
3. В приложении выберите YouTube.
4. Вставьте ссылку.
5. Выберите качество или режим MP3.
6. Запустите загрузку.

### Плейлист

Приложение может определять плейлист по URL. Для плейлистов доступны дополнительные параметры, включая ограничение количества загружаемых элементов и обработку MIX/радио.

Поддерживаются обычные ссылки `youtube.com`, короткие ссылки `youtu.be` и мобильные ссылки YouTube.

## TikTok

1. Откройте видео TikTok.
2. Скопируйте ссылку.
3. В приложении выберите TikTok.
4. Вставьте ссылку.
5. Выберите качество или режим MP3.
6. Запустите загрузку.

Поддерживаются обычные, мобильные и короткие ссылки TikTok.

## Качество и аудио

Для видео доступны предустановленные варианты качества, включая Best, 1080p, 720p, 480p и 360p, когда соответствующий формат доступен на исходной платформе.

Режим **MP3** использует FFmpeg для извлечения и преобразования аудио.

## Cookies

Приложение поддерживает использование browser cookies для сессий, где они необходимы.

В главном меню можно создать `cookies.txt` из поддерживаемого браузера или использовать настройки browser-cookie3.

Поддерживаемые браузеры включают:

- Google Chrome
- Microsoft Edge
- Chromium

Используйте cookies только для собственных сессий и контента, к которому у вас есть законный доступ.

## Интерфейс

Панель инструментов позволяет:

- вернуться в главное меню;
- посмотреть текущую папку загрузки;
- выбрать другую папку;
- открыть папку в Проводнике;
- переключить интерфейс между русским и английским языками.

Во время загрузки приложение показывает прогресс, текущую скорость и ETA, если эти данные доступны от yt-dlp.

## Настройки

Локальные настройки хранятся в:

```text
%USERPROFILE%/.vd_settings.json
```

Среди сохраняемых параметров:

- папка загрузки;
- ограничение скорости;
- количество параллельных фрагментов;
- шаблон имени выходного файла;
- параметры cookies;
- последняя открытая страница;
- язык интерфейса.

## Типичные проблемы

### FFmpeg не найден

Проверьте, что FFmpeg установлен и его `bin`-директория добавлена в Windows `PATH`. После изменения `PATH` перезапустите приложение.

### Ссылка не принимается

Проверьте, что URL относится к поддерживаемому домену YouTube или TikTok и ведёт на доступное видео или плейлист.

### Приватный или ограниченный контент

Для контента, требующего авторизованной сессии, может потребоваться использование browser cookies. Доступность загрузки всё равно зависит от платформы, учётной записи и самого контента.

### Низкая скорость

Проверьте сетевое соединение, лимит скорости в настройках и количество параллельных фрагментов.

## Сборка Windows-версии

Инструкции по сборке находятся в [BUILD.md](BUILD.md).

Кратко:

```bash
python build.py
```

Результат создаётся в `dist/VideoDownloader.exe`.

## Ограничение использования

Используйте приложение только для контента, который вам разрешено загружать, с учётом правил соответствующей платформы и применимого законодательства.
